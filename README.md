# CodeAlpha Image-Gallery

A modern, responsive image gallery built with HTML, CSS, and JavaScript.

The project provides a clean and visually appealing interface for exploring beautiful photographs of nature, travel destinations, cityscapes, and people.

## Features

- Image gallery with a modern dark theme
- Category-based image filtering
- Nature, travel, people, and city categories
- Interactive image hover effects
- Full-screen lightbox image viewer
- Next and previous image navigation
- Image counter in the lightbox
- Keyboard controls for image navigation
- Close lightbox using the Escape key
- Responsive navigation menu for mobile devices
- Smooth animations and transitions
- Responsive design for mobile, tablet, and desktop
- Accessible navigation and button focus styles
  
## Technologies Used

- HTML5 — Structure of the gallery
- CSS3 — Styling, grid layout, animations, and responsive design
- JavaScript — Image filtering, lightbox functionality, navigation, and event handling

## How to Run

No installation or additional software is required.

### Run Locally

- Download or clone this repository.
- Open the project folder.
- Make sure all image files are placed inside the images folder.
- Open index.html in a web browser.
- Explore the gallery and try the different category filters.

### Using a Code Editor

Open the project folder in a code editor such as Visual Studio Code. Open index.html in your browser or use the Live Server extension to run the project locally.

### How to Use

- Home: Return to the main gallery section.
- Photos: Browse the available images.
- Categories: Filter images by Nature, Travel, People, or City.
- Image Viewer: Click an image to open it in the full-screen lightbox.
- Next/Previous: Navigate between gallery images.
- Close: Close the lightbox using the close button or Escape key.
- Mobile Menu: Use the menu button to navigate on smaller screens.
  
## Keyboard Controls
| Key  | Action |
|---|---|
| Escape | Close the lightbox |
| ArrowRight | Show the next image |
| ArrowLeft | Show the previous image |
| Tab | Navigate through focusable controls |
